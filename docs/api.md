#### `verifyBoundaryWeights`

```ts
verifyBoundaryWeights(tol?: number): {
    ok: boolean;
    passed: number;
    failing: number;
    checks: Array<{
      l: number;
      idx: number;
      edge?: number;
      expected: number;
      got: number;
    }>;
  }
```

Cross-checks the projected (exact) boundary degrees of freedom against the
Section 6.3 boundary weights.  Applies each wired weight functional to its
boundary simplex's canonical exact trace basis field and verifies it
recovers the normalized DoF (1), without altering how DoFs are computed.
Call computeBoundaryWeights() first.

**Parameters**

- `tol`: Absolute tolerance (default 1e-6).

**Returns** Result object with ok, passed, failing, and the per-simplex checks.

### `validateMeshInput`

```ts
function validateMeshInput(
  vertices: number[][],
  tetrahedra: number[][],
  options?: { allowFlipped?: boolean },
): void
```

Checks vertices and tetrahedra and throws a ValidateError naming the first
problem: a malformed or non-finite coordinate, an index that is not an
integer or does not name a vertex, a repeated vertex, or a tetrahedron with
degenerate volume. By default a tetrahedron must also be positively
oriented, as `Mesh` and `Projector` require. The operators that take vertices
and tetrahedra call it with `allowFlipped` because they give the same answer
for either orientation.

**Parameters**

- `vertices`: Vertex coordinates.
- `tetrahedra`: Four vertex numbers per tetrahedron.
- `options.allowFlipped`: Accept negatively oriented tetrahedra (default false).

### `parseGmsh`

```ts
function parseGmsh(
  text: string,
  options?: { orient?: boolean },
): {
  vertices: number[][];
  tetrahedra: number[][];
  skipped: Record<string, number>;
}
```

Reads a Gmsh mesh file (ASCII formats 2.x and 4.1) into the two arrays every
operator takes. Only first-order tetrahedra (element type 4) become cells;
points, lines and triangles are counted in `skipped`. Binary files, other
versions, hexahedra, prisms, pyramids and second-order tetrahedra raise a
`ValidateError`, as does any file whose tetrahedra do not make a valid mesh.

**Parameters**

- `text`: The contents of the `.msh` file.
- `options.orient`: Reorder the vertices of negatively oriented tetrahedra so that all are positively oriented, as `Mesh` and `Projector` require (default true).

**Returns** The mesh and how many elements of each ignored kind the file held.

### `StableProjector`

```ts
export class StableProjector
```

part: `Pi u = Pi_boundary u + Pi_zero (u - Pi_boundary u)`.

`ZeroTraceProjector`, so inputs that are unbounded at an interior
mesh vertex are projected stably. The boundary part uses canonical degrees
of freedom (point values, edge integrals, face fluxes), so the input must
have finite such values on the boundary; the paper's weight-based boundary
operator, which tolerates rough boundary data, is not implemented. The
projection commutes with the exterior derivative for fields with a

### `HigherOrderProjector`

```ts
export class HigherOrderProjector
```

Locally L2-bounded commuting projections onto the finite element spaces of
degree p + 1 (Lagrange, Nedelec, Raviart-Thomas, discontinuous), after
Arnold and Guzman (ESAIM M2AN 55, 2021): pi = P + Q (I - P), with P the
lowest-order projection built from local weight functions and Q the
correction onto the forms without lowest-order degrees of freedom. It is a
projection, commutes with the exterior derivative for every L2 input with
an L2 derivative, and each coefficient depends only on the input near its
entity. The weights are sparse local solves (a few seconds each at p = 1),
and the mesh must be fine enough that its extended stars are balls. It does
not preserve nonzero boundary traces; with `boundaryConditions` it maps into
the forms with zero trace.

```ts
      quadratureOrder?: number;
```

**Parameters**

- `vertices`: Vertex coordinates.
- `tetrahedra`: Four vertex numbers per tetrahedron.
- `options.degree`: Polynomial degree p (default 0; the spaces have degree p + 1).
- `options.quadratureOrder`: Gauss points per direction.
- `options.boundaryConditions`: Zero trace on the boundary of the domain: the weights of boundary entities vanish (default false).


Lazy evaluation of the projection of a field: only the coefficients that a

**Parameters**

- `l`: Form degree.

**Returns** Functions giving the value of the projection, and of its exterior derivative (gradient, curl or divergence), at a point of a cell.

### `TracePreservingProjector`

```ts
export class TracePreservingProjector
```

The full trace-preserving projection of Ern, Guzman, Potu and Vohralik:
Pi = mPi (I - Pi_boundary) + Pi_boundary. It is a projection onto the
finite element spaces of degree p + 1, preserves the discrete trace on the
boundary and commutes with the exterior derivative for fields whose trace is
a discrete trace; each value depends on a patch of cells around its point.
It needs a mesh fine enough that the extended stars are balls.

projection has coefficients on their basis. At `degree >= 1` the projection
is evaluated field by field with `local`.
